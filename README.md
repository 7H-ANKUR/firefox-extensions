# Firefox Extensions 🦊

Welcome to my personal repository for custom-built Firefox extensions. Each extension lives in its own dedicated folder for a clean, scalable structure.

## 📦 Current Extensions

### 🔗 [LeetCode to GitHub Sync](./leetcode-to-github) — `v2.6.0`
A powerful Firefox extension that automatically pushes your accepted LeetCode solutions to your personal GitHub repository.

**Highlights:**
- ⚡ Auto-push on Accepted verdict with runtime & memory stats
- 🏢 Company panel on every problem page — see who asked it and how frequently  
- 🔍 Company search in the popup — find all questions any company has asked
- 🛡️ Bulletproof commit logic with safe retry (no force-push, no data loss)

👉 [Install from Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/leet-solution/)
