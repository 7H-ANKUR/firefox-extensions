# Firefox Extensions 🦊

Welcome to my personal repository for custom-built Firefox extensions. This repository is structured to hold multiple independent extensions, with each extension living inside its own dedicated folder.

## 📦 Current Extensions

Currently, this repository contains the following extension:

- 🔗 **[LeetCode to GitHub Sync](./leetcode-to-github)** — A powerful Firefox extension that automatically pushes your accepted LeetCode solutions directly to your personal GitHub repository, complete with runtime and memory stats.

*(More extensions will be added here in the future!)*
