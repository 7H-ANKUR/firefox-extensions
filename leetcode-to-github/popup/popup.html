LeetCode → GitHub

Auto-push accepted solutions to a repo

Needs repo scope (classic PAT) or Contents: Read & write (fine-grained). Create one at github.com/settings/tokens.

How it works
  1. Open any LeetCode problem and solve it as usual.
  2. When your submission is Accepted, the extension captures the exact code you submitted.
  3. It creates/updates NNNN-problem-slug/solution.ext and a README.md in your repo automatically.
  4. No action needed on LeetCode's side — nothing about the site's UI is changed.
